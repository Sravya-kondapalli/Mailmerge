# 📧 Automated Certificate Generator

A lightweight, automated web application built with **Streamlit**, **Pandas**, and **python-docx** that streamlines bulk certificate generation from custom templates and recipient data.

## 🚀 Features
* **Zero UI Template Uploads:** Automatically pulls the template directly from the repository (`templates/certificate_template.docx`).
* **Multi-Format Support:** Accepts both CSV and Excel (`.xlsx`) recipient lists.
* **Safe File Sanitization:** Automatically cleans recipient names to prevent Windows extraction errors.
* **Instant ZIP Download:** Packages all generated Word documents into a single downloadable archive.
